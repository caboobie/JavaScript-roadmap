# Whitley Bay Sharks

A JavaScript command-line application for managing an ice hockey team's
players, games and season statistics.

## Features

- View team roster
- Find players
- View team statistics
- Record games
- View home and away games
- Search games
- View wins, losses and draws
- Edit game information
- Edit player game statistics
- Persistent JSON data storage

## Technologies

- JavaScript
- Node.js
- JSON
- Node.js readline
- File system (`fs`)
- Node.js test runner

## Running the project

npm install
npm start

## Testing

npm test
